CLEARLY: SUPPORT MATRIX (M14, 2026-11-10)
Built only from automated runs and feature detection on this machine (macOS 27.0.1, Apple M3).
"Tested" means a Playwright run passed; "detected" means the feature check returned that value in
that engine; "not tested" is said plainly. The app never branches on browser names: every row is
what feature detection decides at run time.

    no run has confirmed it.
